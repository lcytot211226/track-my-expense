# track-my-expense(個人記帳本)

一個用 Next.js + MongoDB 打造的個人記帳網站。除了基本的收支紀錄,還處理了信用卡分期/結帳週期換算、訂閱固定扣款、房租水電、跨帳號分享、系統公告通知等比較「現實生活記帳」會遇到的細節。

## 快速開始

### 需求

- Node.js(建議 20+)
- 一個 MongoDB 資料庫(本機或 Atlas 都可以)
- 一組 [Resend](https://resend.com/) API Key(寄送註冊 / 忘記密碼驗證信用)

### 1. 安裝套件

```bash
npm install
```

### 2. 設定環境變數

在專案根目錄建立 `.env.local`(**不要**提交到 git):

```
MONGODB_URI=mongodb+srv://<user>:<password>@<cluster>/<dbname>?retryWrites=true&w=majority
JWT_SECRET=<自訂一組亂數字串,用於簽發登入 token>
EMAIL_KEY=<Resend API Key>
```

### 3. 啟動開發伺服器

```bash
npm run dev
```

打開 [http://localhost:3000](http://localhost:3000)。第一次使用請先到 `/register` 註冊帳號,系統會寄送 6 位數驗證碼到信箱,輸入驗證碼啟用帳號後才能登入使用。

### 其他指令

```bash
npm run build   # 建置正式版
npm run start   # 啟動已建置好的正式版伺服器
npm run lint    # ESLint 檢查
```

## 這個記帳本的特色

### 💳 真正貼近信用卡帳單邏輯的分期/單筆消費

一般記帳 App 只看「消費日期」,但信用卡的錢實際上是在「繳款日」才真的離開口袋。這裡每張卡都設定自己的**結帳日**與**繳款日**,系統會依此自動換算每一筆刷卡/分期消費真正的「歸屬月份」(還會處理「結帳當下銀行還沒入帳、要再往後遞延一個月」的情況)。分期消費可以一次輸入總金額與期數,系統自動展開成每期一筆交易並各自算好月份,之後想刪除也是整組一起刪,不會留下斷尾的期數。

### 🔁 訂閱 / 固定月付管理

Netflix、房租清潔訂閱這類每月固定扣款的項目,只要設定一次金額、扣款方式與起始日,之後每個月到期就會自動補上對應的交易紀錄,不用每個月手動記一次;訂閱本身之後調整金額或刪除,都不會動到過去已經生成的紀錄。

### 🏠 房租水電一站式紀錄

租金、電費、水費整合在 `/overview` 同一個區塊,電費/水費可以用「電表度數 × 單價」自動算,也可以直接輸入帳單金額;租金、電費、水費、甚至整組房租水電,都可以個別開關要不要計入當月支出統計。

### 📊 每月總覽 + 每日可花預算

`/overview` 一頁看完當月的收支圖表、房租水電、各張信用卡刷卡總額與對帳狀態、收入/支出列表預覽。設定好個人化的「月結算日」後,還會顯示距離下次結算還有幾天、平均每天還能花多少錢,抓緊荷包。

### 🤝 跨帳號項目分享(合租、共同開銷很方便)

可以把自己某個項目的當月總額(例如「房租水電」「某張卡的刷卡總額」)分享給任何 email,不需要對方先註冊。對方登入後能在自己的總覽頁看到這筆分享金額,並自行決定要不要把它算進自己的收支結算——很適合跟室友分租、或是家人共同分攤開銷的場景。

### 🔔 系統公告通知

管理員可以發布公告,全站使用者的導覽列鈴鐺會顯示未讀提示,點開即可查看。

### 🔐 單一入口登入 + Email 驗證

全站都要先登入才能使用,註冊需要輸入信箱驗證碼才會啟用帳號,也支援忘記密碼流程;登入狀態用 httpOnly cookie 搭配 sliding session,只要持續使用就不用一直重新登入。

### 🌓 深色 / 淺色模式 + 響應式設計

支援深色/淺色主題切換,並針對手機瀏覽做了響應式排版,出門在外也能隨手記帳。

## 技術棧

- **框架**:Next.js(App Router)+ TypeScript,前後端都在同一個專案裡(Route Handlers 當後端 API)
- **資料庫**:MongoDB + Mongoose
- **樣式**:Tailwind CSS
- **認證**:bcryptjs 雜湊密碼 + `jose` 簽發 JWT,存在 httpOnly cookie
- **Email**:Resend(驗證碼信件)
- **圖表**:Recharts
